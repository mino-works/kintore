1. まとめ

  • あなたが答えた体や目標の情報と、トレーニングの記録は、端末の中だけに保存します。開発者にも広告の会社にも送りません。
  • 本アプリには広告が出ます。広告を出すために、Google の広告の部品（Google Mobile Ads SDK）が、広告 ID などの情報を Google に送ります。
  • 広告 ID をトラッキングに使ってよいかは、はじめて開いたときの iPhone の確認で、あなたが選べます。許可しなくても、本アプリはすべて同じように使えます。
  • 広告は、App 内課金の「広告を消す」を購入すると消せます。支払いは Apple が行い、開発者は支払いの情報を受け取りません。
  • アカウント登録やログインはなく、開発者のサーバーもありません。

2. 端末の中だけに保存する情報

本アプリは、あなたに合った筋トレのメニューを作り、分身を表示し、物語を進めるために、次の情報を利用者の端末の中だけに保存します。これらの情報が、開発者、Google、そのほかの第三者に送られることはありません。広告の表示にも使いません。

  • 最初の聞き取りの答え：性別（答えたくないも選べます）、分身の顔、身長、体重、今の体格、なりたい体格、特に鍛えたい部位、トレーニングの場所（ジムか自宅か）、家にある器具、筋トレの経験、1回の量
  • 呼び名（入れた場合）
  • トレーニングの記録：何日目か、日時、種目、重さ、回数、秒数、セット。自宅のサーキットの途中の進み具合。「器具がない」で替えた種目
  • 分身の成長、物語の進み具合、設定（「効果音と音楽」と「音楽」のオン・オフ）、広告の表示の回数の管理（動画の広告を見て、全画面の広告を減らした残りの回数）、見たムービー、使い方の案内と評価のお願いを出したかどうか、通知の設定と、通知の時刻を決めるための最近3回のトレーニングを始めた時刻、「広告を消す」を購入したかどうかの印
  • App Store の評価のお願いは、iPhone の標準の画面（Apple の機能）で出します。評価や感想は Apple に送られ、本アプリと開発者は受け取りません。

性別は、初めに選ばれている分身の顔を決めるためだけに使います。メニューの計算には使いません。身長、体重、体格、経験、1回の量、鍛えたい部位は、メニューの重さ・回数・種目と、分身の見た目を決めるために、端末の中で計算に使います。

これらの情報は、端末の OS の機能（iCloud バックアップなど）によって、利用者自身のバックアップに含まれることがあります。

3. ヘルスケアとの連携

本アプリは、Apple の「ヘルスケア」（HealthKit）とは連携しません。ヘルスケアのデータを読むことも、書き込むこともありません。

4. 広告について（Google AdMob）

本アプリは、Google LLC の広告配信サービス「Google AdMob」を使って広告を表示します。全画面の広告は、トレーニングを終えた後、結果の画面が出る前に出ます。バナーの広告は「ストーリー」の画面に出ます。トレーニングの最中には出ません。

広告の部品が扱う情報

広告を表示し、その効果を測り、不正を防ぐために、Google Mobile Ads SDK が次の情報を Google に送ることがあります。開発者がこれらの情報を受け取って、あなた個人と結び付けることはありません。

  • 端末の ID：広告 ID（IDFA。トラッキングを許可した場合だけ）、アプリや開発者ごとの ID
  • 広告のデータ：表示された広告、広告を押したかどうか
  • アプリの使い方：アプリを開いた回数、広告の動画を見た時間など、広告に関わる操作
  • おおよその位置：IP アドレスから推測した国や地域。本アプリは端末の位置情報の機能を使いません
  • 端末の情報：機種、OS のバージョン、言語
  • 不具合と性能の情報：広告の部品の異常終了の記録、読み込みの時間

Google による情報の扱いは、次のページをご覧ください。

  • Google のプライバシーポリシー：https://policies.google.com/privacy
  • Google のサービスを使うサイトやアプリから収集した情報の Google による使用：https://policies.google.com/technologies/partner-sites

使う目的

  • 本アプリを無料で提供し続けるための広告の表示
  • 広告の表示の回数や効果の測定、不正なクリックの防止
  • トラッキングを許可した場合は、あなたの興味に近い広告の表示

広告を消す購入（App 内課金）

本アプリには、全画面の広告とバナーの広告を出さないようにする、買い切りの App 内課金「広告を消す」があります。購入と支払いは、Apple の App Store の仕組みで行います。お名前、支払いの方法、Apple アカウントなどの情報は Apple が扱い、開発者には届きません。購入の記録は Apple が持ちます。本アプリは、購入したことの印だけを端末の中に保存し、外部へ送りません。本アプリを入れ直したときや、別の iPhone に入れたときは、設定の「購入を復元」で、Apple の記録から印を戻せます。Apple による情報の扱いは、Apple のプライバシーポリシー（https://www.apple.com/jp/legal/privacy/）をご覧ください。

表示する広告の内容

表示する広告には、成人向けの内容（お酒、ギャンブル、成人向けの話題など）が含まれることがあります。そのため、本アプリの App Store の年齢区分は18歳以上（18+）です。不適切な広告は、広告の端の印（AdChoices）から Google に報告できます。

5. トラッキングの許可と、広告の同意

  • トラッキングの許可（App Tracking Transparency）：本アプリを入れてはじめて開いたときに、広告についての説明の後、iPhone の「トラッキングの許可」の確認が出ます。「許可」を選んだ場合だけ、広告 ID が、ほかの会社のアプリやウェブサイトをまたいだ広告に使われます。「App にトラッキングしないように要求」を選んでも、本アプリの機能はすべて同じように使えます。この場合も広告は出ますが、興味に合わせない広告になります。
  • 広告の同意（欧州など）：欧州経済領域、英国、スイスなど、法律で同意が求められる地域では、Google の同意の画面（User Messaging Platform）で、広告のための情報の使い方を選べます。同意の確認ができない間は、本アプリは広告の部品を始めません。

6. 広告の情報を止める・変える方法

  • トラッキングの許可を取り消す：iPhone の「設定」→「プライバシーとセキュリティ」→「トラッキング」で、本アプリをオフにします。すべてのアプリで止めるときは、「App からのトラッキング要求を許可」をオフにします。
  • 欧州などで出る同意を選び直す：本アプリの「設定」（「今日」の画面の右上の歯車）→「広告のプライバシー設定」。この項目は、同意が求められる地域でだけ表示されます。
  • Google の広告のカスタマイズを止める：https://adssettings.google.com
  • 広告の部品に情報を一切送らないようにするには、本アプリを削除してください。

7. 端末の機能

本アプリは、演出のために端末の振動（触覚フィードバック）を使い、トレーニング中は画面が消えないようにします。カメラ、マイク、連絡先、位置情報の機能にはアクセスしません。写真を読み取ることはありません。

通知：1日目のトレーニングの後に、すでにお使いの方は更新後に初めてトレーニングを終えた後に、通知を受け取るかをお聞きし、iPhone の確認で許可した場合だけ通知を出します。通知は、iPhone の中で予約する通知（ローカル通知）です。最後のトレーニングから1日、2日、3日、6日、9日後の5回までで、いつもトレーニングを始める時刻のころに届きます。時刻と文は端末の中で決め、開発者のサーバーや外部のサービスは使いません。本アプリの設定の「通知」、または iPhone の「設定」の「通知」で止められます。

音楽：トレーニング中の音楽は、アプリの中で作る音です。マイクは使わず、外部から音楽を読み込むこともありません。
トレーニングの記録や計画はインターネットにつながっていなくても使えます。広告の表示には通信を使います。

8. 記録の画像の共有

21日分を終えた後に、1日目と21日目の分身を並べた画像を作れます。画像には、身長、体重、呼び名は入りません。「画像を共有」を押すと、iPhone の共有の画面が開き、送り先や「画像を保存」は利用者が選びます。写真への保存は、利用者が「画像を保存」を選んだ時だけ行います。本アプリが自動で画像を送ることはありません。

9. 情報の削除

本アプリを端末から削除すると、本アプリが端末に保存した情報はすべて削除されます。「広告を消す」の購入の記録は Apple が持つため、入れ直した後に「購入を復元」で戻せます。削除した記録は元に戻せません。開発者は利用者の情報を持っていないため、開発者の側で削除や開示をする情報はありません。Google が持つ広告の情報については、6章の方法と Google のページをご覧ください。

10. 第三者への提供

開発者は、利用者の情報を集めていないため、第三者に提供することはありません。4章の広告の情報は、Google Mobile Ads SDK が直接 Google に送るものです。「広告を消す」の購入と支払いの情報は、Apple が扱います。

11. 健康について

本アプリは筋トレの習慣づくりを助けるアプリであり、医療機器ではありません。体の状態を測ったり、診断や治療をしたりするものではありません。痛みや持病がある方は、始める前に医師に相談してください。

12. 子どもの利用

本アプリは18歳以上の方を対象としています（App Store の年齢区分 18+）。子ども向けに作ったものではなく、本アプリ自身は利用者の年齢を確かめる機能を持ちません。開発者は、年齢にかかわらず利用者の情報を集めません。

13. このポリシーの変更

開発者は、必要に応じてこのポリシーを変更します。情報の扱いが変わる機能を加える場合は、その機能を含む更新を配信する前に、このページで変更の内容と改訂日をお知らせします。
